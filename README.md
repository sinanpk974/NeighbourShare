# NeighbourShare

NeighbourShare is a MERN stack platform that allows people in the same local community or village to share useful items with each other.

Users can list their own items, request items from other users, manage borrowing requests, and review their sharing experience.

## Features

* User registration and login
* JWT-based authentication
* User profile management
* Add, edit, and delete items
* Search and filter available items
* Borrowing requests
* Accept, reject, and return requests
* User notifications
* Item and user reviews
* Admin dashboard
* User verification by admin
* User blocking and unblocking
* Account deletion requests
* Admin management of users, items, requests, and reviews

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd NeighbourShare
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open another terminal:

```bash
cd backend
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the backend folder and add the required environment variables.

Do not upload your `.env` file or any secret keys to GitHub.
